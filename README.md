# 全球海啸模拟 Android 数值移植工程

这是对原 `GlobalTsunamiSim v1.6.1` Python 项目的 Android 移植工程，不是圆环动画或预填假预警。工程内的 Java `TsunamiModel` 实现真实的网格数值推进，并使用原项目随包提供的海底地形数据重采样生成资产。

## 已移植的核心功能

- **真实浅水方程推进**：球面经纬网格、Arakawa-C 交错网格、CFL 时间步、科氏力、边界海绵层、弱双调和滤波、浅水底摩擦及陆海界面无通量边界。
- **断层源初始场**：由 Mw 推算断层尺度与地震矩，按断层走向/倾角生成有正负瓣的初始海面形变；输入深度按断层顶部深度解释。导入 USGS 事件时，会以破裂中部近似将目录震源深度换算为断层顶部深度。阿拉斯加-阿留申高震级事件有原项目同类的宽度/振幅修正。
- **真实地形**：`app/src/main/assets/data/global_depth_1deg.f32` 来源于原始全球 `global_bathy.nc`，降采样为 1°；`nwpac_depth_025deg.f32` 来源于原始 GMRT `nwpac_bathy.nc`，经地理参考点校正数据方向后重采样到 0.25°。水深为正，陆地为负，均为 little-endian float32。
- **地图与沿岸结果**：显示真实地形及当前数值水位，用户可点击地图选择震中；沿岸最大正水位、首次在采样帧中超过 2 cm 的时刻和最大波时刻由模型输出计算，不会按震级预置。
- **地震目录导入**：可联网读取 USGS 最近 30 天 Mw 6+ 地震事件，并将事件震级、位置和深度填入参数。
- **结果保存**：可将当前传播图保存为 PNG。
- **中文界面**：适配 Android 12 及较新的 WebView。

## 分辨率与范围

- `全球`：使用 1° 全球地形网格（经纬范围约 360° × 144°，覆盖 72°S–72°N），以便在手机硬件上推进全球模式。
- `西北太平洋`：使用 0.25° 网格，范围 100°E–180°E、0°–60°N。
- `中国沿岸`、`日本周边`、`马里亚纳周边`：作为地图视图和沿岸结果筛选范围；震中位于西北太平洋时，仍用完整西北太平洋计算域，以便保留跨区域传播。若震中在该区域外，则自动使用全球地形网格。
- 每 5 分钟模拟时间输出一帧，界面时间为模拟时间；时间步由 CFL 条件自动计算。更高分辨率与更长时长会增加耗时。

## 编译 APK

需要 Android Studio / Android SDK 与 Gradle 8.9+（工程使用 Android Gradle Plugin 8.7.3、compileSdk 35）。在 Android Studio 打开本目录并等待 Gradle Sync 后，运行 **Build → Build APK(s)**。生成路径通常为 `app/build/outputs/apk/debug/app-debug.apk`。

命令行（已设置 Android SDK 环境变量）可运行：

- Linux/macOS：`./build-apk-unix.sh`
- Windows：`build-apk-windows.bat`

当前制作容器没有安装 Android SDK/Gradle，也无法解析外部下载域名，所以这里不能实际链接 Android 框架或签出 APK。模型核心已可用本机 JDK 单独编译与执行自检；完整 APK 需在具备上述 Android 构建工具的环境中构建。工程验证结果：西北太平洋 0.25° 算例完成 6 小时积分（约 1,109 步），全球 1° 模式完成 1 小时测试，状态量保持有限；24 小时区域模式最长时长测试亦保持有限。另与原版 Python 求解器对照固定西北太平洋算例前 100 步，水域水位最大绝对差约为 1.2×10⁻⁶ m；`tools/verify-model.sh` 包含一个固定基准值回归检查。该对照是实现一致性测试，不代表模型已通过现实海啸事件验证。

## 模型限制

这是面向科普和数值方法学习的线性浅水模型，不包含非线性爬高、海啸淹没、波浪破碎、完整 Okada 位错解或官方海啸预警逻辑。全球模式使用 1° 网格，区域模式使用 0.25° 网格；结果会受源模型、数据重采样和网格分辨率影响。模型等级只是估算，不能用于现实灾害警报、疏散和安全决策。
